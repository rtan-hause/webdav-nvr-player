# Security policy

webdav-nvr-player serves security-camera footage, so please report vulnerabilities privately rather than in a public issue.

## Reporting a vulnerability

Use GitHub's private reporting: **Security → Report a vulnerability** on this repository, or go straight to <https://github.com/rtan-hause/webdav-nvr-player/security/advisories/new>.

Include what you found, how to reproduce it, and the version (image tag or commit) you tested. This is a personal project, so responses are best-effort, but reports are read.

## Supported versions

Only the latest release gets fixes.
